# OpenTutor: обработка исключений в Python

Кейс по повышению надёжности backend на базе [OpenTutor](https://github.com/zijinz456/OpenTutor). Решение [задачи №18](https://github.com/zijinz456/OpenTutor/issues/18): уточнение типов перехватываемых ошибок и улучшение диагностики.

## Изменения

- 27 широких обработчиков заменены на конкретные ошибки SQLAlchemy, HTTPX, Playwright, SDK моделей и файловых форматов.
- Добавлены сообщения с контекстом операции и трассировкой ошибки. Ошибки программирования больше не скрываются в изменённых обработчиках.
- 15 защитных обработчиков сохранены на границах фоновых задач, пользовательского кода и расширений; причины описаны в комментариях.
- Добавлены 14 регрессионных проверок. Поддержка необязательных зависимостей сохранена.

## Проверка

Windows, Python 3.12.14; исходная версия — `f14968a`.

| Версия | Успешно | Сбоев | Пропущено | Покрытие |
|---|---:|---:|---:|---:|
| Исходная | 979 | 4 | 5 | 49,86% |
| С исправлением | 993 | 4 | 5 | 50,11% |

Четыре одинаковых сбоя воспроизводятся в исходной версии: два теста исполнения кода и два теста загрузки материалов. Новых падений в полном прогоне нет. Отдельная проверка затронутых маршрутов и новых сценариев: **42 теста прошли**.

## Файлы

- [solution.patch](solution.patch) — все изменения для просмотра и применения к исходной версии.
- [Регрессионные тесты](test_exception_handling_regressions.py) — проверка ожидаемых сбоев, журналирования и распространения ошибок программирования.

Для проверки клонируйте OpenTutor на версии `f14968a`, примените патч командой `git apply solution.patch`, установите зависимости по исходному README и выполните `python -m pytest tests -q`. Патч включает новые тесты. Код распространяется по [лицензии MIT](LICENSE).
